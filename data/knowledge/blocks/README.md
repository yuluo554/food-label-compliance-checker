## 引用格式与守门

- 规则集 `basis.quote_ref` 引用格式：`<file_id>.json#<条款号>`（如
  `gb7718-2011.json#4.1.3.1.2`）；`basis.clause` 为语义条款号（含表格时如
  「附录C 表C.1」），二者可不同（表格正文归属见下）。
- 守门测试 `tests/test_blocks.py`：四文件齐全、块号唯一、关键数值条款按
  去空白口径挂原文核对（NRV 基准值、能量系数 17/37/17、无糖阈值 ≤0.5、
  允许误差 ≤120%、修约间隔 1、盐油糖提示语、"不添加"同义语等）。
- PDF 提取的小数偶有拆行（如 "0."/"5g"），匹配一律用「去全部空白」口径。

## 归属口径

- 附录中「表X.Y …」表格标题行把表格正文归位到语义条款块（表C.1 → 块C.1）；
  正文「表1/表2…」流入其所属条款块（§6.2 的表1 → 块6.2）。
- 正文条号必须挂在当前章下、章号顺序递增（页脚/表内数值不误判），条号独行时
  标题向下一短行借取——切分规则详见 `tools/build_blocks.py` 模块注释。
- 标准文本版权归发布机构，仅供学习研究；本目录 JSON 为自制切分物
  （本仓库 MIT），所含标准原文以 raw/ 官方 PDF（sha256 台账见 raw/retrieval-log.md）为准。

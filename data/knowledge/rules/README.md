## 确定性近似口径（诚实边界，plan/06 D20/D21）

1. **日期格式（FMT-DATE）**：按 D16/D19 契约以 `YYYY年MM月DD日` 为判定基准（2011 C.3 月日两位有明文；2025 A.2.1 允许的等价形式会被一并从严标出，结论已注明可复核）。
2. **配料递减序（ING-ORDER）**：无配料占比数据，采用品类先验对（果汁饮料：水/苹果汁 先于 白砂糖；发酵乳：生牛乳 先于 白砂糖/食用香精），仅先验对被颠倒才报；其余形态转人工/LLM 兜底。
3. **豁免判定（conditional）**：关键词近似标准豁免清单；酒精度数值无法自动核验 → 转待人工确认。
4. **到期日推算（DATE-LOGIC）**：月加法日截断/天加法为生成器约定（D16），GB 未明文规定推算方法。

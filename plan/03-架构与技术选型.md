# 03 架构与技术选型

> 上游：[02-需求解读.md](02-需求解读.md)。定稿日期：2026-10-04（M0）。

## 1. 分层架构

```
输入层        文本标签(.txt/.md/粘贴) /（缓冲）图片 OCR
   │
解析层        规则优先解析器（正则+槽位+合法性校验）  ──兜底──▶  LLM 抽取适配器（可选）
   │                │                                      │
   ▼                ▼                                      │
中间表示      标签参数卡 LabelCard（字段-值-单位-置信度-证据）◀──┘
   │
知识层        三层知识库：标准原文(raw) → 条文块(blocks) → 机器可读规则表(rulesets/*.json)
   │          规则集版本化：gb7718-2011 / gb7718-2025 / gb28050-2011 / gb28050-2025
   ▼
规则引擎      按 check_type 分派；类目隔离门控(only_if)；数值复算子引擎(NRV%/能量折算/声称阈值)
   │          判定三级：合规 / 不合规 / 待人工确认；每条 Finding 挂{依据条款+证据}
   ▼
编排层        轻量状态机 Pipeline（节点/边/重试/耗时），双标尺并行跑 + 对照
   │
交付层        CLI(flcheck) ─ Web 面板(FastAPI 内联单页, 0 外链) ─ docx 报告 ─ 基准脚本(bench)
```

关键原则：

1. **协同归约为结构化对齐**：输入与规则两端都落到"参数卡/规则表"结构化表示，比对=字段对齐。
2. **规则优先、LLM 只兜底**：解析、数值结论、判定全部确定性实现；LLM 仅在解析置信度低/别名归一/报告行文时启用，且候选行压缩+逐字摘录校验（防幻觉三件套）。
3. **规则集版本化**：引擎不感知版本，版本只是不同的 ruleset JSON；双标尺=同一引擎跑两个 ruleset 后 diff。
4. **类目隔离门控**：每个规则可带 `only_if` 关键词门控，对引擎**全部** check_type 生效（含 conditional/checklist 分支），防跨类目误查。
5. **零依赖核心**：解析→参数卡→规则→判定的核心通路纯 stdlib，保证基准零 API 依赖可重复。

## 2. 技术选型

| 维度 | 选型 | 理由 | 备选 |
|---|---|---|---|
| 语言 | Python ≥ 3.8 | 本机 3.8.8 实测；下限对齐 3.8，语法用 `from __future__ import annotations` | — |
| 打包 | setuptools + src 布局 + pyproject.toml | 3.8 兼容、CI 矩阵稳；dist 名=仓库名，包名 `food_label_checker` | poetry/flit |
| 核心依赖 | **无（纯 stdlib）** | 基准可复现、断网可跑、干净 venv 装得快 | — |
| web extra | FastAPI + uvicorn + python-multipart | 免构建内联单页；`UploadFile` 隐式依赖 multipart（实测漏声明启动即崩，必须显式声明） | Flask |
| report extra | python-docx | 报告 docx 导出 | — |
| llm extra | httpx（OpenAI 兼容 REST） | qwen3 系走 dashscope 兼容模式，`enable_thinking=false`；缺依赖时惰性导入+安装提示+降级 | openai SDK |
| 测试 | pytest | — | — |
| CI | GitHub Actions：{ubuntu, windows} × {3.8, 3.11}，装 `.[dev,web,report]` 后 pytest | 覆盖 Windows 编码/EOL 差异；装全 extras 防"静默少跑" | — |
| 知识索引 | 规模小：纯 Python 余弦相似度（条文块检索） | 不引 faiss | faiss（数据量大时） |

## 3. 依赖分层（extras 契约）

| extra | 包 | 用途 |
|---|---|---|
| （默认） | 无 | 解析+规则+判定+CLI 全功能 |
| `dev` | pytest, httpx | 测试；httpx 为 FastAPI TestClient 测试期依赖（漏声明会静默少跑，M5 加 extras 守门测试锁死） |
| `web` | fastapi, uvicorn, python-multipart | Web 面板 |
| `report` | python-docx | docx 报告 |
| `llm` | httpx | LLM 兜底（与 dev 复用 httpx，但语义独立声明） |

**契约**：① 任何新 import 必须落到对应 extra 并加守门测试（M5）；② 核心通路 import 不允许触达任何 extra 包（用"裸 venv 装默认组跑全量测试"验收）。

## 5. 关键工程决策（实测教训前置）

1. **0 外链单页**：Web 采用 vanilla JS + 内联 CSS 单文件（无构建/无 vendor/无 CDN），`/docs`、`/redoc` 显式关闭（Swagger 引 CDN）。
2. **EOL 冻结前置**：`.gitattributes` 第一天入库；M1 冻结 fixtures 后加"CR 出现即大声失败"守门测试。
3. **Windows 编码**：脚本/CLI 输出 UTF-8（`sys.stdout.reconfigure` 或 `py -X utf8`）；测试不断言中文控制台输出。
4. **惰性导入范式**：`_import_fastapi()` 等缺依赖时抛带 `pip install food-label-compliance-checker[web]` 提示的异常；CLI 捕获打印说明并降级退出，不崩溃。
5. **CI 触达 extras**：CI 装 `.[dev,web,report]` 全组并跑全量 pytest，防 extras 缺测试期依赖的"静默少跑"。

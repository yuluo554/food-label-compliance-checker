## 2. 功能需求清单（FR，带优先级）

| ID | 需求 | 说明 | 优先级 | 里程碑 |
|---|---|---|---|---|

## 3. 非功能需求（NFR）

| ID | 需求 | 验收口径 |
|---|---|---|
| NFR-1 | 可复现性 | 基准零 API 依赖（纯规则通路）可重复；生成器固定 seed |
| NFR-2 | 指标门槛 | 解析 F1 ≥ 0.95；端到端误报 0（植入差异检出率目标 M4 定，初设 ≥0.9） |
| NFR-3 | 断网可用 | Web 页面 0 外链；演示全链断网可跑；核心功能（解析/校核/CLI）零依赖纯规则 |
| NFR-4 | 免责与定位 | 标签合规审查定位（非营养咨询/非真伪鉴定），报告带免责声明 |
| NFR-5 | 开源质量 | README（含评测表/限制/已知环境问题）、LICENSE、测试、CI、贡献友好目录结构 |
| NFR-6 | 数据合规 | 全合成标签（品牌虚构）；NRV/能量系数入库挂出处；查不到标"待核对" |
| NFR-7 | 测试纪律 | 全绿含失败路径（缺文件/坏格式/LLM 不可达降级）；干净环境（新 clone+新 venv）按 README 逐条跑通，pytest 收集数与 dev 一致 |

## 4. 边界与非目标（防 scope 失控，题目第六节固化）

- **不做**：真实品牌/产品标签（全部合成）；产品真伪鉴定；营养健康建议；OCR 为加分项不承诺。
- **品牌隔离**：独立项目品牌，不复制姊妹项目代码，文档不提其他领域业务。
- **结论纪律**：无出处的规则不得落库、不得以确定语气写进结论；查不到显式标"待核对"。
- **LLM 边界**：LLM 永远不产生数值结论，只做兜底抽取/归一/复核/行文；默认关闭（规则通路完整可用）。

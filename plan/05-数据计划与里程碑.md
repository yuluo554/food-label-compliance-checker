## 1. 数据计划（阶段1 数据先行）

### 1.1 四类目录

| 目录 | 内容 | 来源 |
|---|---|---|
| `data/label_samples/` | 手写样例标签（含最小骨架样例，虚构品牌） | 自制 |
| `data/generated/` | 生成器产物（固定 seed；冻结 fixtures 策略 M1 定：基准用小集入仓+守门测试，大批量产物不入仓） | 程序化自制 |

### 1.2 标准原文获取计划（查证优先于自证）

纪律：WebSearch 摘要一律不采信数值，只用可直连官方页面原文核验；每条入库挂{标准号+条号+渠道}；两个渠道查不到 → 登记待核对清单继续推进，不编造不停摆。

### 1.3 合成标签生成器（核心资产，M1）

- 位置：`src/food_label_checker/datagen/`，CLI：`flcheck gen --seed --n --categories --out`。
- 品类模板：乳制品（灭菌乳/发酵乳）、饮料（果蔬汁/茶饮）、烘焙（面包/饼干）、调味品（酱油/醋）——模板含全部强制项的"干净版"。
- 品牌全虚构（名单固定在生成器内，如"牧云""禾序"等），品类真实、数值物理合理。
- 注入违规类型（每类带注入器，真值自动落 JSON）：

| 注入 | 违规语义 | 真值主期望 |
|---|---|---|
| V1 缺强制标示项 | 随机删 1–3 项（净含量/生产日期/贮存条件/SC 等） | 对应 mandatory 规则不合规 |
| V2 NRV% 算错 | 营养表某行 NRV% 偏离复算值超容差 | nrv_recalc 不合规（also_expect：该行级结论） |
| V3 能量折算矛盾 | 能量标示值偏离系数折算 | energy_consistency 不合规 |
| V4 营养声称超阈值 | 标"无糖"但糖含量超阈 | claim_threshold 不合规 |
| V5 "零添加"类新规违规 | 2025 版受限声称 | 2025 规则集不合规（2011 通过 → 双标尺差异样例） |
| V6 配料递减序错误 | 排序破坏且占比 >2% | ingredient_order 不合规 |
| V7 日期格式/逻辑错误 | 格式不规范或生产日期+保质期与到期日矛盾 | format / date_logic |
| V8 功能声称白名单外 | 白名单外功能声称 | claim_whitelist |

- 复现性：固定 seed + 版本号（生成器版本写入真值 JSON）；`--force` 重生成位级一致（M1 加守门测试）。
- 真值 JSON schema：`{sample_id, seed, generator_version, category, injections: [{type, main_expect: {rule_id, level}, also_expect: [...]}], clean_baseline: bool}`。
